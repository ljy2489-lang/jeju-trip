# 제주 가족여행 인터랙티브 일러스트 여행 지도 — 설계

- 작성일: 2026-10-12
- 상태: 설계 승인됨 (대화에서 1~4절 승인)

## 1. 목적과 성공 기준

**목적**: 2026-10-16(금)~18(일) 제주 2박 3일 가족여행 중 아이폰으로 열어, 제주 지도 위에서 날짜별 동선·장소 정보·아이 동반 정보를 한눈에 보고 일정을 조정하는 웹앱.

**사용자**: 가족(성인 4명 + 8개월·16개월 아이 2명). 링크로 공유, 로그인 없음.

**성공 기준**
1. 아이폰 Safari에서 링크를 열면 제주 지도와 오늘 일정이 보인다.
2. 날짜 탭을 누르면 해당 날 경로(실제 도로)와 순서 마커만 표시되고 지도가 맞춰 이동한다.
3. 마커·카드를 누르면 상세(사진/일러스트, 운영정보, 아이 정보, 출처)가 열리고, 식당은 어른/8개월/16개월 메뉴가 구분된다.
4. 항공 도착·출발시간을 입력하면 일정 시간이 재계산되고 경고·생략 제안이 갱신된다.
5. 순서 변경·제외·체류시간 수정이 되고 새로고침 후에도 유지된다.
6. 확인되지 않은 정보는 '확인 필요'로 표시되며 사실처럼 만들지 않는다.
7. GitHub Pages 공개 주소로 접속된다.

## 2. 기준 일정 (사용자 확정본 = 추천 코스)

- 인원: 성인 4명 + 아이 2명(8개월·16개월), 렌터카
- 항공 기본값(가정): 금 11:00 도착 / 일 21:00 출발

**DAY1 금** 공항(11:00 도착, 12:15 출발) → 성산갈치맛집 점심(13:30) → 아쿠아플라넷 제주(14:40) → 수유·휴식(16:40) → 섭지코지 짧은 산책(17:00, 등대 계단 제외, 생략 가능) → 표선해녀의집 저녁(18:10) → 제주해양경찰수련원 체크인(19:25)

**DAY2 토** 숙소 아침(08:00) → [선택] 당케올레국수(08:30) → 휴애리(10:00) → 중문어촌계 해녀의집 점심(12:00) → 신화월드 짐보관·수유·낮잠(14:00) → 서머셋 체크인(15:00, 고정) → 탐모라 실내수영장(15:30, 고정 ⭐) → 정리(17:00) → 난드르바당 저녁(18:00, 대안 고바진) → 숙소(20:00)

**DAY3 일** 아침·짐정리(08:00) → 체크아웃(09:40) → 신화테마파크(10:00) → 신화월드 내 점심(12:00) → 아침미소목장(14:10) → 낮잠·이동, [선택] 용담해안도로 카페 → 착한집 저녁(17:00, 대안 도도리고기국수) → 주유(18:00) → 렌터카 반납·셔틀(18:30) → 공항(19:00) → 출발(21:00)

**전체 방문 코스**: 위 + 기획안 희망지 중 제외된 해일리 베이커리 카페(DAY1) 및 선택 일정 전부 포함.

## 3. 구조

순수 HTML/CSS/JS, 빌드 없음. Leaflet(CDN) + 래스터 타일(CARTO Voyager 등, 파스텔 CSS 필터). PWA(manifest + service worker).

```
jeju-family-trip/
├─ 작업일지.md
├─ index.html, styles.css, app.js
├─ schedule.js            # 순수 계산 모듈 (DOM 무관, Node 테스트 가능, UMD)
├─ data/places.js         # 장소 정보 + 필드별 검증 상태
├─ data/itinerary.js      # 코스별 일정 정의
├─ data/routes.js         # 미리 계산한 도로 경로
├─ assets/                # 직접 만든 SVG 스티커/일러스트, 아이콘
├─ manifest.json, sw.js
├─ tools/build-routes.py  # OSRM으로 routes.js 생성
└─ tests/schedule.test.js # node --test
```

### 데이터 모델

```js
// places.js
{ id, name, type: 'airport'|'sight'|'food'|'cafe'|'stay'|'rest',
  lat, lng, sticker, photo: {url, credit} | null,
  info: {               // 각 필드: {value, status:'verified'|'check', source?, checked?}
    address, hours, price, stay, parking, stroller, nursing, kids, links },

// itinerary.js

  { placeId, kind:'visit'|'meal'|'rest'|'stay'|'transfer', stay:minutes,
    fixedAt?:'15:00', optional?:true, note? } ] }] },
  full: {...} }

// routes.js
routes = { 'a>b': { coords:[[lat,lng]...], minutes, km, source:'OSRM' } }
```

## 4. 일정 계산 (schedule.js)

- `computeDay(day, places, routes, opts)` → 각 stop의 `arrive`, `depart`, `driveToNext`, `routeKind('road'|'straight')`, 경고 목록.
- 이동시간: routes에 `a>b` 또는 `b>a`가 있으면 사용, 없으면 haversine × 1.3 / 40km/h, `straight`로 표시.
- 시작: DAY1 = 도착 + 75분. DAY2/3 = 08:00.
- 고정 일정(`fixedAt`): 도착이 이르면 대기(여유), 늦으면 `fixedLate` 경고.
- DAY3 마감: 터미널 = 출발 − 120분, 반납 = − 150분, 주유 = − 180분. 계산된 종료가 마감 초과 시 `deadline` 경고 + 생략 제안.
- 생략 제안: `optional` stop을 체류+우회 절감 시간과 함께 제안(절감 큰 순).
- 경고: 하루 운전 > 180분, 휴식 없는 연속 활동 > 180분, 일몰(10/16~18 제주 약 17:50, 계산값) 이후 야외 visit, 식당 마지막주문 이후 도착(확인된 경우만).
- 사용자 수정(override): `{order:[], excluded:[], stay:{placeId:min}}`을 localStorage에 코스·날짜별 저장. 항공시간도 저장. 버전 키로 데이터 변경 시 초기화.

## 5. 화면

- 상단 고정: 제목·날짜·일러스트, 탭(전체/DAY1/DAY2/DAY3), ✈️ 항공시간, 코스 전환.
- 지도(상단 약 55%): 날짜 색 경로(DAY1 감귤 #F08A3C, DAY2 바다 #1FA2A6, DAY3 목장 #5BAA5B), 도로 실선/직선 점선, 구간 시간 라벨(추정), 번호 스티커 마커, 내 위치·전체보기 버튼.
- 하단 시트: 타임라인 카드(시간, 이름, 유형 칩, 체류, 다음 운전시간, 👶 팁, 카카오맵 버튼, 경고). 카드↔마커 양방향 연동.
- 상세 시트: 사진/스티커, 정보 항목마다 ✅확인(출처)/⚠️확인 필요, 식당 메뉴 탭(어른/8개월/16개월).
- 전체 탭: 3일 경로 동시 표시, 코스 비교 카드, 아이 식사 안내, 출발 전 체크리스트(체크 상태 저장).
- 편집 모드: ▲▼ 순서, 제외/복원, 체류 ±10분, 기본값 복원.
- 길찾기: `https://map.kakao.com/link/to/{이름},{lat},{lng}`.
- 접근성: 터치 44px 이상, 본문 15px 이상, safe-area 대응, 색 외 텍스트로도 구분.

## 6. 정보 검증 원칙

- 위치: 카카오맵 장소 검색 + 주소 대조(제주해양경찰수련원은 유사 명칭 혼동 주의).
- 운영 정보: 공식 홈페이지 우선, 확인일 2026-10-12, 출처 URL 기록. 미래 날짜 영업은 '정기휴무 기준 + 방문 전 재확인'.
- 블로그만 있는 정보는 단정하지 않고 '확인 필요'.
- 사진은 라이선스가 명확한 것(위키미디어 등)만, 없으면 일러스트 + 공식 링크.
- 날씨는 기상청 링크로 대체, 일몰은 계산.
